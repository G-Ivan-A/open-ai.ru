{%- comment -%} Вывод одного файла content/*.md на веб-странице — дословно, без правки слов. Markdown → HTML делает kramdown (markdownify); шаблон меняет только уровень и оформление заголовков и оборачивает таблицы для горизонтальной прокрутки. Параметры: source — Markdown файла (include_relative content/…md); id — id раздела страницы; heading — "page": H1 и строка под ним выводятся в первом экране (hero.html), здесь — только разделы H2 (как h2); "section": H1 файла → h2 раздела, H2 → h3 в раскрывающемся блоке (details), H3 → h4; skip — заголовки H2, которые на веб-странице не выводятся, через «|». {%- endcomment -%} {%- capture nl %} {% endcapture -%} {%- assign h2_split = nl | append: "## " -%} {%- assign h3 = nl | append: "### " -%} {%- assign h4 = nl | append: "#### " -%} {%- assign skips = include.skip | default: "" | split: "|" -%} {%- assign parts = include.source | split: h2_split -%} {%- assign head_lines = parts.first | split: nl -%} {%- assign doc_title = head_lines.first | remove_first: "# " | strip -%} {%- assign doc_intro = parts.first | remove_first: head_lines.first | strip -%} {%- assign section = include.heading | default: "section" -%}
{%- if section == "section" %}

{{ doc_title | escape }}

{{ doc_intro | markdownify }}
{%- endif %} {%- for part in parts offset: 1 -%} {%- assign part_lines = part | split: nl -%} {%- assign part_title = part_lines.first | strip -%} {%- if skips contains part_title -%}{%- continue -%}{%- endif -%} {%- assign part_body = part | remove_first: part_lines.first -%} {%- assign part_html = part_body | prepend: nl | replace: h3, h4 | markdownify | replace: "", '
' | replace: "
", "
" -%} {%- if section == "section" %}

{{ part_title | escape }}
{{ part_html }}
{%- else %}

{{ part_title | escape }}

{{ part_body | markdownify | replace: "", '
' | replace: "
", "
" }}
{%- endif -%} {%- endfor %}
